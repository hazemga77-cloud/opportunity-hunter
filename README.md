# Opportunity Hunter — صائد الفرص

نسخة أولية قابلة للتشغيل على Streamlit، بواجهة عربية، لفحص قائمة رموز أسهم أمريكية.

## تشغيل محليًا
```bash
pip install -r requirements.txt
streamlit run app.py
```

## النشر المجاني
1. أنشئ مستودع GitHub جديدًا باسم `opportunity-hunter`.
2. ارفع `app.py` و`requirements.txt`.
3. افتح https://share.streamlit.io/
4. اختر المستودع والفرع `main` والملف `app.py` ثم Deploy.

## حدود النسخة الأولى
- البيانات من Yahoo Finance عبر yfinance؛ ليست تغطية شاملة لكل السوق وقد تتأخر أو تنقص.
- اكتب رموز الأسهم في القائمة الجانبية لتوسيع/تغيير نطاق الفحص.
- Insider Buying لا يحصل على نقاط لأن المصدر المجاني لا يقدمه بشكل موثوق في هذا التطبيق.
- DCF مبسط ويجب اعتباره تقديرًا حساسًا للافتراضات، وليس قيمة عادلة مؤكدة.
- مستويات وقف الخسارة والأهداف إرشادية محسوبة من ATR وليست توصية.
- فلتر الشريعة معروض كخيار مستقبلي، لكنه غير منفذ حتى ربط مصدر متخصص.

## تحسينات المرحلة التالية
1. إضافة مصدر موثوق للقوائم المالية (مثل SEC CompanyFacts) مع معالجة أسماء البنود.
2. إضافة مصدر Insider Transactions مستقل.
3. بناء قائمة أسهم أمريكية واسعة وتحديثها دوريًا.
4. اختبار تاريخي (Backtesting) وتوثيق جودة النتائج.
